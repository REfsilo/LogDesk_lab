# LogDesk Lab

Учебная система заявок для темы «Логирование и отладка тестов».

## Что показывает проект

- логирование HTTP-запросов;
- логирование успешных действий пользователя;
- логирование ошибок валидации;
- учебную серверную ошибку 500;
- PyTest-тесты для Flask-приложения;
- Selenium UI-тесты;
- сохранение скриншота при падении Selenium-теста.

## Запуск

```bash
python -m venv venv
```

Windows PowerShell:

```powershell
venv\Scripts\Activate.ps1
```

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск приложения:

```bash
python app.py
```

Адрес приложения:

```text
http://127.0.0.1:5000
```

## Запуск тестов

Во втором терминале:

```bash
pytest -v
```

## Важные папки

```text
logs/app.log              # файл логов приложения
reports/screenshots/      # скриншоты при падении Selenium-тестов
```

## Учебные маршруты

```text
/             Главная страница
/debug/slow   Медленный запрос
/debug/crash  Учебная ошибка 500
/api/tickets  API со списком заявок
/test/reset   Очистка данных для тестов
```
